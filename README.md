# Evidence Autosalonu (Java Core Projekt)

Tento projekt je jednoduchá konzolová aplikace vytvořená v čisté Javě (bez použití externích frameworků). Slouží jako ukázka mých znalostí základů objektově orientovaného programování (OOP).

## Co projekt umí:
* Přidávat, odebírat a vyhledávat vozidla (Osobní auta, Nákladní vozidla, Motocykly).
* Ochrana proti vložení duplicitních vozidel (hlídáno pomocí VIN kódu).
* Rozdělení logiky do vrstev (`entities`, `service`).

## Použité technologie a principy:
* **Java 25**
* **OOP principy:** Dědičnost, Polymorfismus, Zapouzdření
* **Kolekce:** Práce s `List`
* **Exception Handling:** Vlastní ošetření chybových stavů (`try-catch`, vyhazování standardních výjimek)
* **Javadoc** pro dokumentaci kódu

## Jak spustit:
Aplikaci lze spustit spuštěním metody `main` ve třídě `Main.java`.
